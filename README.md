## How to Run

### Option 1: 1-Click Desktop App (Easiest)
Simply double-click:
```
FileAnomalyScanner.exe
```
located directly in this root folder! It immediately launches the application without opening any terminal or requiring any commands.

### Option 2: Run via Terminal
1. Open terminal in `backend` folder and run:
   ```bash
   dotnet run
   ```

### Option 3: Live Frontend Development (HMR)
1. In `backend`: `dotnet run`
2. In `frontend`: `npm run dev`
3. Open `http://localhost:5173` in your browser.
